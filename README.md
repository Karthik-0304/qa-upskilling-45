# 45-Day QA Upskilling Program: Manual QA to Automation Engineer

This repository tracks a 45-day intensive upskilling program transitioning from manual QA to a professional Automation Engineer specializing in **Playwright with TypeScript/JavaScript**. The program is structured around 2 hours of daily deliberate practice (1 hour of theory and 1 hour of hands-on coding).

## Tech Stack

* **Language:** JavaScript / TypeScript


* **Automation Tool:** Playwright


* **Version Control:** Git & GitHub


* **CI/CD:** GitHub Actions

## How to Run Locally

1. Clone the repository:
```bash
git clone https://github.com/YOUR_USERNAME/qa-upskilling-45.git

```


2. Install project dependencies:
```bash
npm install

```


3. Run the test suite:
```bash
npx playwright test

```
